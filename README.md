# mod-profession-xp
AzerothCore module for xp reward when gathering and crafting

# L'idée
- crafter / récolter un objet pour la première fois donne une forte récompense d'xp 
- crafter / récolterun objet compliqué (orange) donne une bonne récompense d'xp
- crafter / récolter un objet (jaune) donne une récompense d'xp
- crafter / récolter un objet facile (vert) donne une petite récompense d'xp

Si le joueur est niveau maximum et que le mod https://github.com/Adrestie/mod-spheregrid est installé, il gagne un montant de sphérite à la place
